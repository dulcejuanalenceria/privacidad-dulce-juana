Política de Privacidad

Última actualización: 4 de septiembre de 2026

Desarrollador: Dulce Juana Lencería

En Dulce Juana Lencería respetamos la privacidad de nuestros usuarios y nos comprometemos a proteger la información relacionada con el uso de nuestra aplicación.

1. Información que recopilamos

La aplicación Dulce Juana Lencería funciona principalmente como un catálogo digital de productos.

La aplicación no requiere que los clientes creen una cuenta ni proporcionen una contraseña para consultar el catálogo.

La aplicación no solicita directamente al usuario datos personales como nombre, dirección, ubicación, contactos, información de pago, fotografías personales, datos de salud o información financiera para utilizar las funciones principales del catálogo.

Algunas preferencias y datos relacionados con la experiencia de uso, como productos favoritos, productos agregados a un pedido y determinados datos necesarios para conservar preferencias, pueden almacenarse localmente en el dispositivo del usuario.

2. Pedidos y WhatsApp

Cuando el usuario decide realizar una consulta o enviar un pedido, la aplicación puede abrir WhatsApp para permitir la comunicación voluntaria con Dulce Juana Lencería.

El usuario decide qué información proporcionar mediante dicha comunicación. La información enviada a través de WhatsApp queda además sujeta a las políticas de privacidad y condiciones de uso de WhatsApp.

3. Información del catálogo

La aplicación utiliza servicios de infraestructura tecnológica para obtener información del catálogo, incluyendo nombres de productos, códigos, precios, categorías, imágenes, disponibilidad y otras características comerciales.

Esta información corresponde al catálogo comercial de Dulce Juana Lencería y no constituye información personal del usuario.

4. Datos personales

Dulce Juana Lencería no utiliza la aplicación para crear una base de datos de cuentas personales de clientes.

No vendemos ni alquilamos información personal de nuestros usuarios.

Si un usuario decide proporcionar voluntariamente información personal durante una comunicación o pedido, dicha información será utilizada únicamente en la medida necesaria para atender la consulta, gestionar el pedido o mantener la comunicación solicitada.

5. Almacenamiento local, conservación y eliminación

Algunos datos relacionados con la experiencia de uso pueden almacenarse directamente en el dispositivo del usuario.

Estos datos pueden incluir preferencias, favoritos, productos agregados a un pedido y datos relacionados con pedidos guardados localmente.

Estos datos permanecen en el dispositivo mientras sean necesarios para la experiencia de uso y pueden eliminarse mediante las herramientas de administración de datos del dispositivo o mediante la desinstalación de la aplicación.

La aplicación no mantiene una cuenta personal del cliente que requiera un proceso independiente de eliminación.

6. Servicios de terceros

La aplicación utiliza servicios de terceros necesarios para su funcionamiento, incluyendo servicios de base de datos, alojamiento y almacenamiento de imágenes.

Estos servicios pueden procesar información técnica necesaria para proporcionar sus funciones y están sujetos a sus propias políticas de privacidad y condiciones de uso.

La aplicación también puede abrir WhatsApp cuando el usuario decide realizar una consulta o enviar un pedido.

7. Seguridad

Adoptamos medidas razonables para proteger la información utilizada por la aplicación y limitar el acceso no autorizado.

Sin embargo, ningún sistema de almacenamiento o transmisión de información por Internet puede garantizar una seguridad absoluta.

8. Menores de edad

La aplicación está destinada a la consulta de un catálogo comercial y no está diseñada específicamente para recopilar información personal de menores de edad.

9. Cambios en esta política

Podemos actualizar esta Política de Privacidad cuando resulte necesario, por ejemplo, ante cambios en la aplicación, en los servicios utilizados o en los requisitos legales.

La versión actualizada se publicará en esta misma página indicando la fecha de su última actualización.

10. Contacto

Si tenés preguntas, consultas o solicitudes relacionadas con esta Política de Privacidad o con el tratamiento de información asociado a la aplicación, podés comunicarte con Dulce Juana Lencería mediante los canales de contacto disponibles dentro de la aplicación.

11. Eliminación de información

La información almacenada localmente en el dispositivo puede eliminarse utilizando las opciones de administración de datos del dispositivo o desinstalando la aplicación.

En el caso de información que el usuario haya enviado voluntariamente mediante WhatsApp, cualquier solicitud relacionada con esa información deberá gestionarse a través del canal correspondiente, teniendo en cuenta las políticas y sistemas de conservación aplicables a dicho servicio.

12. Aceptación

Al utilizar la aplicación Dulce Juana Lencería, el usuario reconoce haber leído esta Política de Privacidad.
